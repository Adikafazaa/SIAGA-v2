# Design System

## Typography
- **Primary Font:** Inter, sans-serif (Teks antarmuka, pesan chat)
- **Monospace Font:** JetBrains Mono (Metrik telemetri, token, status log)

## Color Palette
- **Primary Care Blue:** `#2563EB` (Aksen utama, tombol chat, active states)
- **Safe Emerald:** `#16A34A` (Status Aman / ALLOW)
- **Caution Yellow:** `#CA8A04` (Status Waspada / WATCH)
- **Probe Purple:** `#7C3AED` (Status Interogasi Aktif / PROBE)
- **Threat Red:** `#DC2626` (Status Terblokir / BLOCK)
- **Background Light:** `#F8FAFC` (Tampilan antarmuka pasien)
- **Background Dark Slate:** `#0F172A` (Tampilan dashboard analitik/SOC)

## Layout & Components
- **Base Grid:** 8px
- **Border Radius:** 12px s/d 16px
- **Icons:** Lucide React
- **Charts:** Recharts (Visualisasi kurva momentum risiko)
- **Accessibility:** WCAG AA (Kontras teks minimum 4.5:1, status dilengkapi teks dan ikon).
