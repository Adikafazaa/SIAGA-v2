# Tech Stack

## Frontend
- **Framework:** Next.js 14+ (App Router, TypeScript)
- **Styling:** Tailwind CSS, Shadcn UI
- **Icons:** Lucide React
- **Visualisasi & Charts:** Recharts (Kurva Momentum CIM & Graf Telemetri)
- **State & Data Fetching:** TanStack Query & Context API
- **Form & Validation:** React Hook Form + Zod

## Backend & Keamanan
- **API Framework:** FastAPI (Python 3.11) + Uvicorn
- **Security Inference Engine:** ONNX Runtime (CPU INT8 MiniLM-L12 / IndoBERT)
- **Mathematical & Graph Core:** NumPy, Scikit-learn, NetworkX (Graph DAG)
- **Session Cache:** DuckDB / SQLite (In-Memory)
- **Environment Management:** Python-dotenv / Pydantic Settings

## Local AI Integration
- **Local Model Runner:** Ollama / vLLM / LocalAI / LM Studio (OpenAI-compatible API)

## Database & Cloud Services
- **Authentication:** Firebase Auth
- **Database:** Cloud Firestore
- **Storage:** Firebase Storage
- **Deployment:** Docker & Docker Compose
